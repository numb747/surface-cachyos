# 01 · 安装

## 一次性：把这台机器装到能用

按顺序。前两步要 sudo，**自己跑**，脚本只打印清单不改系统。

### 1. 内核与传感器栈

```bash
./setup/01-surface-kernel.sh          # 先看命令清单
./setup/01-surface-kernel.sh --run    # 确认后执行
```

装四样：

| 包 | 干什么 |
|---|---|
| `linux-surface` | IPTS 触屏/触控笔驱动**不在主线内核里**，必须换内核 |
| `linux-surface-headers` | hyprpm 编译 hyprgrass 要用，缺了插件装不上 |
| `iptsd` | IPTS 的用户态守护进程，触屏的实际数据处理在这 |
| `iio-sensor-proxy` | 把加速计暴露到 D-Bus，自动旋转的前提 |

再从 AUR 装 `iio-hyprland-git`（读加速计转屏幕）和 `wvkbd-deskintl`（虚拟键盘）。

然后把 surface 内核提到 Limine 菜单第一位：

```
BOOT_ORDER="*surface, *, *lts, *fallback, Snapshots"
```

**`*` 兜在第二位是关键。** surface 内核哪天因为内核升级坏了，开机菜单选第二项就
回到普通内核 —— 不用 live USB 抢救。这是本机敢用 surface 内核的底线。

重启，验证：

```bash
uname -r                      # 应含 surface
systemctl status 'iptsd@*'    # active
```

### 2. hyprgrass 触屏手势

```bash
./setup/02-hyprgrass.sh       # 只打印，不执行
```

然后**在真终端里**逐条手敲那三条 `hyprpm` 命令。

> ⚠ 不要 `yes | hyprpm add`，也不要后台跑。hyprpm 每条命令末尾跑 `sudo -k`
> 清掉 sudo 时间戳，管道顶替 stdin 会让 sudo 认证失败，而报错信息完全误导
> （`Failed to write plugin state`）。详见 `docs/04-坑.md`。

> ⚠ 不要用 AUR 的 `hyprgrass-git` —— 它停在 2025-08。要从 git 编译，
> `hyprpm.toml` 里 pin 的 commit 才是本机 Hyprland 0.56.2 对得上的那个。

### 3. 装本仓

```bash
cd ~/surface-config
./install.sh                  # 四个模块全装
./doctor.sh                   # 体检
```

`hypr` / `hook` / `osk` 三个模块只写 `$HOME`，不需要 sudo。`sensor` 模块的目标在
`/etc`，脚本会打印你要自己跑的 `sudo install` 命令。

## 日常：同步主仓之后

**这是最容易忘的一步。**

```bash
cd ~/cachyOS-config && ./sync.sh --pull     # 主仓对齐远程
cd ~/surface-config && ./install.sh hook    # ★ 把挂钩插回去
./doctor.sh                                 # 确认
```

主仓的 `--pull` 会把 `hyprland.lua` 和 `autostart.lua` 覆盖成远程版本 ——
那是纯 PC 的版本，没有 `require("config.touch")`，也没有 `iio-hyprland`。
所以触屏手势和自动旋转会一起失效。

`hook` 模块是幂等的：挂钩还在就什么都不改，被冲掉了就重新插。

## 内核升级之后

hyprgrass 是按 Hyprland 的 ABI 哈希编译的。**内核升级本身不影响它**，
但 Hyprland 升级会影响 —— 插件的 ABI 哈希里编进了 Hyprland 的 commit。

症状：`hyprctl plugin list` 里找不到 hyprgrass，触屏拖窗口失效，
但其它一切都正常。

处理：

```bash
hyprpm update
hyprpm reload -n
```

如果还不行，说明 ABI 变化大到插件需要改源码：

```bash
hyprpm remove hyprgrass
hyprpm add https://github.com/horriblename/hyprgrass
hyprpm enable hyprgrass
```

## 验收清单

```bash
./doctor.sh
```

全绿即正常。它检查六组：

1. 内核是不是 surface 的
2. `iptsd` 在不在跑
3. D-Bus 上有没有 `net.hadess.SensorProxy`
4. hyprgrass 加载了没、`sensitivity` 是不是 4.0
5. 主仓那两个文件里的挂钩还在不在
6. 虚拟键盘的三个部件齐不齐

第 4 组的 `sensitivity = 4.0` 是重点：**插件加载 ≠ 配置生效**。
如果它是 1.0，说明 `touch.lua` 没被 require（挂钩被冲掉了）。
