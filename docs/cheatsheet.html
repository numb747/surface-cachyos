平板操作速查

Surface Pro 6 · Hyprland · 摘掉 Type Cover 时用

常见操作 顶栏按钮 手势 虚拟键盘键位 出问题时

常见操作

打开应用 / 找窗口三指点击 → 启动器，输入名字搜索
关掉当前应用Alt+W
新建桌面Alt+T
切换桌面点顶栏中间的工作区圆点
全屏 / 退出全屏四指点击，或 Alt+Enter
移动窗口三指按住不动，等窗口跟手后再拖
切到 PC 模式五指长按，或 Alt+M
切到平板模式拔掉 Type Cover，或 Alt+M
打字点输入框会自动弹键盘；没弹就从屏幕底边往下划。PC 模式下不弹
音量 / Wi-Fi / 亮度四指长按 → 控制中心；音量也可用侧边实体键
复制过的内容五指点击 → 剪贴板历史
锁屏点顶栏 🔒
躺着看不让屏幕转点顶栏 ⟳
看小说用侧边键翻页长按顶栏 ⟳，音量− 下一页、音量+ 上一页

顶栏按钮

右上角电池、音量旁边的三个图标。长按 = 次要动作。

⌨ 键盘点：显示 / 隐藏虚拟键盘（PC 模式下不弹）
⟳ 旋转点：锁定 / 解锁自动旋转（躺着看视频、小说）
长按：侧边音量键变翻页键（音量− 下一页，音量+ 上一页），再长按变回
🔒 锁屏点：锁屏，锁屏上会自动弹出键盘输密码
长按：电源菜单（关机 / 重启 / 注销）

5 分钟不碰屏幕会熄屏，碰一下就亮；在放声音（视频、音乐）时不熄屏。

手势

三指点击启动器（应用 + 窗口搜索）
三指长按拖动窗口
四指点击切换全屏
四指长按控制中心
五指点击剪贴板历史
底部边缘下滑显示 / 隐藏虚拟键盘
双指长按仅平板救援：界面乱了、屏幕空了时复位
五指长按仅平板退出平板模式

长按 = 按住约半秒不动。只有点击和长按，没有滑动手势。

虚拟键盘键位

  1. 从屏幕底边往下划，呼出键盘
  2. 点一下 Alt（会保持按下状态）
  3. 再点字母，键盘自动收起
Alt+W关闭窗口
Alt+T新建桌面（空工作区）
Alt+Enter切换全屏
Alt+M切换平板 / PC 模式

点了没反应？先看键盘上的 Caps 是不是亮着 —— 大写锁定开着时快捷键全部失效。

键盘左下角的 ⌨ 是切换布局，不是收起。接着 Type Cover 时这些键直接按。

出问题时

屏幕只剩壁纸 / 窗口"不见了"双指长按（救援）
划动写字时断断续续屏幕上有两条竖直的死线（竖屏时左起约 4 cm、8 cm 处），横着穿过会断。上下滚动不受影响。 想亲眼看哪里坏：打开 触屏地图，到处划，红点就是断开处
Firefox 顶部冒出菜单栏点一下页面别处即可消失
模式不对（有键盘却是平板）Alt+M 或五指长按
